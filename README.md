
# CoLang (Colang)

**CoLang** — это язык программирования для системного программирования, изучения архитектуры процессора и создания собственных компиляторов.

Проект находится в стадии активной разработки. Сейчас создается архитектура компилятора **CLC (CoLang Compiler)** и интерпретатора **CL**.

## 🚀 Возможности
- Поддержка архитектур: **x86 (DOS)**, **x32 (Linux/Windows)**, **x64 (POSIX)**.
- Собственный рантайм: **BASIO**, **WINIO**, **DOSIO**.
- Асинхронный вывод через `wait(5) && oprint(...)`.
- Понятный синтаксис на основе `ustart` и `uend`.
- Компиляция через NASM/MASM.

## 📁 Структура проекта
- `src/` — исходный код компилятора CLC (на C).
- `runtime/` — библиотеки для разных ОС (BASIO, DOSIO).
- `examples/` — примеры программ на CoLang.

## 📄 Пример кода
```colang
.use BASIO

func main ustart
    oprint("Hello, world!\n")
    return(success) >> main
uend
```
