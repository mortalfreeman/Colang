# 🚀 CoLang Compiler (CLC)

**CLC** — это экспериментальный компилятор общего назначения для языка программирования **CoLang** (`.cl`), написанный на чистом языке Си (C99). Компилятор транслирует исходный код CoLang в ассемблер x86_64 (с использованием синтаксиса NASM), автоматически компилирует его и собирает в готовый нативный исполняемый файл с помощью GCC и встроенной библиотеки времени выполнения (Runtime).

---

## 📂 Структура проекта

Проект организован по модульному принципу, разделяя фазы трансляции (лексический анализ, синтаксический разбор, семантика и кодогенерация):

```text
.
├── Makefile              # Автоматическая сборка компилятора
├── src/
│   ├── ast.h             # Определение структур Абстрактного синтаксического дерева (AST)
│   ├── ast.c             # Конструкторы и деструкторы узлов AST
│   ├── lexer.h           # Лексический анализатор (токенизатор)
│   ├── lexer.c           # Реализация лексера
│   ├── parser.h          # Синтаксический анализатор (парсер)
│   ├── parser.c          # Реализация парсера (превращает токены в AST)
│   ├── semantic.h        # Заголовок семантического анализатора
│   ├── semantic.c        # Проверка типов, областей видимости и дубликатов
│   ├── codegen_x64.h     # Заголовок генератора кода x86_64
│   ├── codegen_x64.c     # Трансляция AST в ассемблер NASM
│   ├── runtime.c         # Библиотека времени выполнения (ввод/вывод, паузы)
│   └── main.c            # Главная точка входа (оркестрация конвейера)
