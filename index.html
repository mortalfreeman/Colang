CoLang (CLC)

Современный, лаконичный и быстрый процедурный язык программирования с нативной трансляцией в x86_64.

✨ Что такое CoLang?

CoLang — это кастомный язык программирования, разработанный для создания эффективных нативных приложений. Он транслируется через собственный компилятор в чистый ассемблер (NASM) и собирается с помощью GCC со своей собственной легковесной библиотекой времени выполнения (runtime).

Главные особенности языка:

  • Четкая блочная структура без лишних фигурных скобок (ustart / uend).
  • Строгая типизация (<int>, <flt>, <txt>).
  • Простой и интуитивный синтаксис ввода-вывода и асинхронных пауз.

🚀 Точка входа и базовая структура

Любая программа на CoLang обязана содержать функцию main. Тела функций и управляющих конструкций оборачиваются в пары ключевых слов ustart и uend.

# Пример базовой программы
func main 
ustart
    # Код программы пишется здесь
uend

📦 Переменные и типы данных

Для создания переменных используется связка make var имя[размер] <тип>. Для строковых переменных (txt) размер в квадратных скобках задает длину буфера в байтах.

Присваивание значений выполняется через оператор let.

func main 
ustart
    make var count[1] <int>
    make var name[32] <txt>
    
    let count = 42
    let name = "Алексей"
uend

💬 Ввод и вывод данных

Вывод на экран осуществляется с помощью oprint (поддерживает форматирование в стиле C, например, %lld), а интерактивный ввод от пользователя — через itaker.

func main 
ustart
    make var username[64] <txt>
    
    itaker("Введите ваше имя: ", username)
    oprint("Привет, находчивый кодер! \n")
uend

🔀 Условия и Циклы

Язык поддерживает классические ветвления (if, elsif, else) и циклы с предусловием (while), а также операторы управления break и continue.

func main 
ustart
    make var i[1] <int>
    let i = 0

    while i < 3 
    ustart
        oprint("Итерация цикла: %lld\n", i)
        let i = i + 1
    uend
uend

⏱️ Паузы и асинхронность

Конструкция wait(секунды) && действие позволяет приостановить выполнение программы на заданное время.

func main 
ustart
    oprint("Ждем 2 секунды...\n")
    wait(2) && oprint("Время прошло!\n")
uend
